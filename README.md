# 사주결

국내 출생자의 생년월일로 사주와 오행을 풀이하고, 일회성 관계 리포트를 체험하는 모바일 웹 MVP입니다. 기준 가격은 4,900원이고, 미리보기 결제의 청구액은 0원입니다. 풀이와 리포트는 전통 명리의 상징을 바탕으로 한 규칙 기반 문구를 제공하며, 계산과 모의 결제는 로컬에서 실행됩니다.

## 실행

Node.js 22 이상과 Bun을 사용합니다.

```bash
bun install
bun run dev
```

[로컬 사이트](http://localhost:3000)에서 양력·음력 생년월일을 선택하세요. 출생 시각은 직접 입력하거나 ‘시각 모름’을 선택할 수 있습니다. 무료 풀이 뒤 ‘관계 리포트 열기’에서 모의 결제를 체험하고, ‘내 리포트’에서 복구·환불·삭제할 수 있습니다.

무료 결과의 **주제별 운세 보기**에서 재물운, 직업운, 연애운, 결혼운, 건강운, 학업운, 자녀운, 궁합, 대운, 아홉수를 볼 수 있습니다.

무료 결과의 핵심 요약은 태어난 날의 첫 글자(일간)와 그 오행을 근거로 표시합니다. **사주 글자와 오행 보기**에는 확인된 각 글자의 대표 오행과 여덟 글자 중 확인된 수가 나옵니다. 재물·직업·학업 풀이의 오행 개수도 같은 기준이며, 미확정 글자가 있으면 집계가 달라질 수 있음을 표시합니다. 이 집계는 천간·지지의 겉 글자 빈도입니다. [한국민족문화대백과사전 사주](https://encykorea.aks.ac.kr/Article/E0025957)

## 주제별 풀이 기준

- 재물·직업·학업은 태어난 날의 첫 글자를 중심으로 오행의 관계를 읽는 재성·관성·인성에서 각각 단서를 가져옵니다. 확인된 글자의 대표 오행을 세며, 직업운은 태어난 달의 두 번째 글자도 참고합니다. 연애·결혼은 태어난 날의 글자로 애정 표현과 생활 방식에 관한 질문을 각각 제시하고, 자녀운은 태어난 시각에 해당하는 글자를 돌봄 방식과 연결합니다. 건강운은 휴식과 생활 리듬을 살피는 질문으로 구성합니다. 모든 문구는 전통 개념을 바탕으로 사주결이 작성한 간략한 규칙 기반 풀이입니다. [명리학의 오행과 육친 관계 연구](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002007564)
- 궁합은 양쪽의 태어난 날 첫 글자의 오행 관계와 두 번째 글자의 합·충을 비교해 대화와 일상에서 맞춰 볼 점을 안내합니다. [한국민족문화대백과사전 궁합](https://encykorea.aks.ac.kr/Article/E0006817)
- 대운은 태어난 해의 첫 글자의 음양과 사용자가 선택한 남성·여성 기준으로 방향을 정합니다. 태어난 달의 간지에서 한 칸씩 움직여 10년 주기 10개를 만들고, 출생 시점과 앞뒤 절기의 간격은 3일을 1년으로 환산해 가장 가까운 월 단위로 표시합니다. 절기 근사값의 앞뒤 10분과 시각 미상에 따른 시간 범위를 시작 나이 범위에 반영합니다. 기준 간지를 확정할 수 없는 경계 사례에는 그 이유를 표시합니다. [사주명리의 대운계산법 검토](https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART003221050), [대운과 행운 세수 계산](https://encyclopedia.catholic.or.kr/entry/2945)
- 아홉수의 기본값은 한국 기준 현재 날짜와 양력으로 환산한 생일을 비교하는 만 나이입니다. 세는나이를 선택하면 현재 연도에서 출생 연도를 뺀 뒤 1을 더합니다. 결과에는 현재 해당 여부와 다음 해당 나이·연도가 표시됩니다. [국립국어원 온용어 아홉수](https://kli.korean.go.kr/term/trgtWord/indexTrgtWord.do?trgtWordNo=2319188)

주제별 풀이의 두 사람 출생 정보와 대운 계산 기준은 POST 요청으로 받아 계산합니다. 결과나 원본 입력을 데이터베이스에 저장하는 단계는 없습니다.

## 계산 기준

- 양력 환산 기준 1989년 1월 1일부터 한국 기준 오늘까지의 국내 출생을 지원합니다. UTC+9, 자정 일주 교체, 두 시간 단위 시주를 적용합니다. 진태양시와 출생지별 보정은 적용 범위에서 제외했습니다.
- 한국 음력 변환에는 `korean-lunar-calendar@0.4.0`을 사용합니다. 연주와 월주는 태양 황경 근사식으로 구한 입춘과 절입을 기준으로 합니다. 계산 버전은 `kst-midnight-v1`이며, 근사 절입 전후 10분과 시각 미상의 절입일에는 영향받는 주를 미확정으로 처리합니다.
- 공식 역서의 2020년 윤4월 초하루와 일진, 입춘 사례를 대조했습니다. 상용화 전에는 지원 전 연도의 절입 시각을 공식 역서 또는 정밀 천체력과 대조해야 합니다. [한국천문연구원 2020년 역서](https://astro.kasi.re.kr/file/astro_almanac_pdf/20200624134708539.pdf)

## 주문과 저장

- 기본 실행은 `.saju-data/`의 PGlite와 로컬 서버 키를 사용합니다. Neon을 연결하려면 `.env.example`을 참고해 `.env.local`에 `DATABASE_URL`과 32바이트 이상의 `SAJU_SECRET`을 설정한 다음 `bun --env-file=.env.local run db:migrate`를 실행하세요.
- 비회원 생년월일과 시각은 URL·브라우저 영구 저장·DB에 넣지 않습니다. 모의 주문은 파생 계산값을 생성 기간에만 보관하고, 완료 시 리포트로 교체합니다. 복구 코드와 세션은 검증용 해시로 저장하고, 코드 복구 시 이전 세션을 교체합니다. 조회는 30일 만료 조건을 적용합니다. 만료 레코드는 다음 모의 주문 생성 때 정리합니다.
- 유료 생성과 모의 환불 상태는 ‘내 리포트’에서 갱신합니다. 최초 시도와 최대 두 차례 재시도를 지원합니다. 환경에 `SAJU_SIMULATE_FAILURE=1`을 지정하면 각 주문의 첫 생성이 실패해 재시도 화면을 확인할 수 있습니다.

## 검증

```bash
bun run typecheck
bun run test
bun run build
```
